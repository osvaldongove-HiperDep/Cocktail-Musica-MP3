# Cocktail Musica MP3

Plataforma musical gratuita focada em Moçambique e países de língua portuguesa.

## Versão 1.0 (atual)

- Página inicial responsiva
- Pesquisa que abre resultados oficiais no YouTube
- Secção de Catálogo Autorizado (pronta para conteúdos com licença)
- Espaço para promoção de artistas
- Design mobile-first

## Como colocar online de graça (sem capital)

### Opção 1 – Netlify (mais fácil)
1. Cria conta grátis em https://www.netlify.com
2. Arrasta a pasta completa deste projeto para o Netlify
3. O site fica online em segundos com endereço tipo: `cocktail-musica-mp3.netlify.app`

### Opção 2 – GitHub Pages
1. Cria conta no GitHub
2. Cria um repositório novo
3. Faz upload dos ficheiros
4. Ativa GitHub Pages nas definições

## Próximos passos recomendados

1. **Legal**
   - Regista o nome “Cocktail Musica MP3” (se possível)
   - Cria email profissional grátis (Gmail ou Proton)
   - Só adiciona músicas com autorização escrita ou Creative Commons

2. **Conteúdo**
   - Contacta artistas locais moçambicanos para autorização
   - Usa sites como Free Music Archive ou Jamendo para Creative Commons

3. **Monetização**
   - Quando tiveres algum tráfego, pede aprovação no Google AdSense
   - Cria pacotes de promoção para artistas (ex: 500 MZN / 1000 MZN)

4. **Melhorias futuras**
   - Sistema de download real de ficheiros autorizados
   - Página de artista
   - Integração com WhatsApp para partilha
